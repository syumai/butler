# Butler character studies

Four standalone proposals, not applied to the app or the main logo.
All use formalwear, a moustache and a bow tie, without skin tones or serving props.

- **01 Faceted**: angular badge and white geometric moustache.
- **02 Orbit**: circular silhouette and curved white moustache.
- **03 Monogram**: B-shaped formalwear with a compact geometric moustache.
- **04 Floating**: separated moustache, bow tie and lapels; no enclosing body.

Each SVG has a transparent 1024 × 1024 PNG export. `comparison.svg` / `comparison.png` show all four on white cards. Colors: teal, deep teal, cool white, muted mint and gold (bow tie only).

Regenerate a PNG with `rsvg-convert -w 1024 -h 1024 01-faceted.svg -o 01-faceted.png`.
