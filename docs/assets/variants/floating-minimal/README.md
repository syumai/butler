# Floating — simplified studies

Four further reductions of [04 Floating](../04-floating.svg). These are standalone proposals and are not applied to the app or main logo. Each uses only teal and gold, without skin tones, a face, limbs or props. Shading, coat tails and the bow knot have been removed.
